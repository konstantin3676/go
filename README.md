# Проект Go

Репозиторий содержит два независимых Go-модуля:

- `gateway` — HTTP-шлюз с эндпоинтом для проверки работоспособности;
- `ledger` — консольное приложение будущего сервиса бизнес-логики.

## Требования

- Go 1.25 или новее

## Запуск Gateway

Из корня репозитория выполните:

```bash
cd gateway
go run .
```

Сервер будет доступен на порту `8080`. Проверьте его из другого терминала:

```bash
curl -i http://localhost:8080/ping
```

В ответ сервер вернёт статус `200 OK` и строку `pong`.

## Запуск Ledger

Из корня репозитория выполните:

```bash
cd ledger
go run .
```

Приложение выведет:

```text
Ledger service started
```
